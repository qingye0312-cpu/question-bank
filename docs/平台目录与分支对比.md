## 构建入口

仍从仓库根目录运行 `pnpm tauri dev` / `pnpm tauri build`。共享脚本 `scripts/tauri.mjs` 根据本机平台选择配置；显式 `--target` 优先于本机平台，用户额外 `--config` 可覆盖默认平台设置，`--` 后的 Cargo 参数原样传递。原生 Tauri CLI 不经过该脚本，直接调用时须手动传 `--config mac/tauri.conf.json` 或 `--config windows/tauri.conf.json`。

Tauri 通用配置、应用标识、前端路径及 Cargo 清单保留在 `src-tauri/`。平台图标配置中的相对路径也以 `src-tauri/` 为基准。Rust 通过条件编译及显式模块路径使用 `mac/src/ocr.rs` 或 `windows/src/ocr.rs`，两端共用输入校验、匹配算法及数据模型。

各平台配置把自己的目录加入 `additionalWatchFolders`，使 `tauri dev` 能监听移出的原生代码。直接运行 `cargo test/build` 时，共享 `build.rs` 会在没有 CLI 配置的情况下加载目标平台配置，并传给 Tauri 编译宏，保证图标与部署设置仍可用。

依赖、工具链、生成资源、安装包、本机题库与日志仍按 `.gitignore` 留在本地；本次整理不包含已构建安装包。Mac 和 Windows 均需在各自系统上打包。

# 导入格式与离线题库包规范 v1.0

适用于题库程序 v0.1.0。Excel、Word、JSONL 共用同一数据模型。当前支持单选、多选和判断，正文为纯文本，可含换行和代码。

## 推荐录入流程

1. 在程序「录题模板」下载 Excel，或使用项目 `templates/题库导入模板_v1.xlsx`。
2. 从「题目」工作表第 2 行开始，一行一题。第 1 行字段名与顺序不变。
3. 新题的「系统ID」「基准修订号」留空。更新已有题目时，从系统导出整行进行修改，保留这两个字段。
4. 导入文件，检查数量、样例和错误，再确认。任意结构错误都会阻止整批写入。
5. 需要分发时，选择该题库并「制作离线包」。阅读端也具有相同制包能力。

## Excel / Word 字段

| 字段 | 填写规则 |
| --- | --- |
| 外部编号 | 可选文本，例如 `NET-001`；不是数据库身份，允许不同题库复用 |
| 题型 | 必填：`单选`、`多选`、`判断` |
| 题库 | 可选；导入到已有题库时以目标题库为准。新建题库取首题填写的名称，空白时使用文件名 |
| 章节 | 可选，例如 `开发基础/组件` |
| 题干 | 必填，保留换行、空格和代码 |
| 选项A—选项H | 选择题填写 2—8 个连续选项；判断题全部留空 |
| 答案 | 单选 `B`；多选 `A|C`；判断 `正确` 或 `错误`。不能用红字或勾号代替 |
| 解析 | 可选纯文本；没有解析时留空 |
| 标签 | 可选，多个标签用 `|` 分隔 |
| 难度 | `简单`、`中等`、`困难` 或空白 |
| 适用版本 | 可选，例如 `HarmonyOS NEXT / API 12`；未知留空 |
| 来源说明 | 可选，文档名称、章节或网址 |
| 系统ID | 新题留空；更新时保留程序导出的 UUID |
| 基准修订号 | 新题留空；更新时必须保留程序导出的正整数 |

系统导出时会额外带「记录元数据」列或字段，以保留来源、选项 ID、内部状态等。不要自行删改该 JSON。它不是人工录题的必填字段。

Excel 只读取「题目」表；「填写说明」必须含模板版本 `1.0`。「示例」和「字段字典」仅供参考。输入以 `=` 开头的代码时应保持文本格式，不能把单元格变成 Excel 公式。表头新增、缺失或拼错会被拒绝。

Word 保留开头的「模板版本 / 默认题库」表，每题一个固定两列表格：左列字段名，右列内容。复制整张表新增题目；删除不用的示例表。不能合并单元格或嵌套表格。正文中散落的自由排版题目不属于标准格式。

本版拒绝图片、Office 原生公式、宏、嵌入对象、Word 修订等不支持的内容，避免静默丢失。普通文本中的 `x²`、`a+b`、LaTeX 字符串可以作为文本保存，不会渲染成公式。

## JSONL

UTF-8 编码，一行一个完整 JSON 对象，不要把文件写成 JSON 数组。`schema_version`、`type`、`stem`、`answer` 必填。示例：

```json
{"schema_version":"1.0","type":"multiple","stem":"下列哪些数是偶数？","options":[{"key":"A","content":"2"},{"key":"B","content":"3"},{"key":"C","content":"4"}],"answer":["A","C"],"bank":"数学基础","external_id":"MATH-001","tags":["偶数"]}
```

- `type`：`single` / `multiple` / `true_false`；判断的 `options` 为空数组，`answer` 为 JSON 布尔值。
- 选择题 `answer` 是选项字母数组，不是字符串；字母必须对应存在的选项，不能重复。
- `question_id`、选项 `option_id` 新建时可省略；系统生成 UUID。带 `question_id` 时必须带 `base_revision`，过期修订会被拒绝。
- `difficulty`：`easy` / `medium` / `hard` / 空字符串。
- `status`：`unreviewed` / `verified` / `needs_review`；普通新题仍须有有效答案。
- `attachments` 当前只能是空数组，`extensions` 只能为空值；新字段不能随意增加。
- 历史迁移中已有原文来源而答案暂未确定的题，才允许 `needs_review` 与 `answer: null`；普通录题模板不允许用此方式绕过答案校验。

完整字段见 `question.schema.json`。结构校验不证明知识答案正确。题目页面只展示最终录入答案；已解决的历史冲突不再额外提示，审校依据保留在来源中。

## 离线包

扩展名必须为 `.qbank.zip`，ZIP 内只含以下两个文件；当前不接受附件目录：

```text
manifest.json
questions.jsonl
```

清单包含 `schema_version`、`bank_id`、`name`、`release_id`、`release_version`、`published_at`、`min_app_version`、`question_count` 和 `files`。当前版本号分别为 `1.0` 和 `0.1.0`。`release_id` 为 JSONL 原始字节的 SHA-256，`files` 同时记录路径、哈希与字节数。

发布只打包当前题库未删除的题目。它保留题目顺序、系统 ID、修订号、来源记录及当前答案；不包含完整编辑历史和回收站。重新制包不改题库身份、题目和版本，制包时间可能更新。修改内容应建立可编辑副本；副本获得新身份。

导入规则：

- 新题库 ID：建立本机只读发布题库，仍可随时再次制包。
- 同 ID、同版本、同内容：跳过重复导入，不增加题目。
- 同 ID、更高版本：预览差异后原子更新；保存上一个版本供回退；如有后续编辑则阻止直接回退。
- 同 ID、较旧版本或同版本不同内容：拒绝覆盖。
- 本机同 ID 的题库可编辑：拒绝发布包覆盖，防止丢失维护内容。
- ZIP 路径穿越、重复成员、符号链接、清单数量或 SHA-256 不符：拒绝；失败不更改数据库。

文件上限 256 MiB，解压后的总内容上限 512 MiB，单题 JSON 上限 1,000,000 字节。超限请按题库拆分。SHA-256 用于检查完整性，不是发布者签名，不提供身份认证。

## 常见错误

| 错误示例 | 正确写法 |
| --- | --- |
| 多选答案填 `AC` / `A、C` | Excel / Word 使用 `A|C` |
| JSONL 判断答案填 `"正确"` | 使用 `true` |
| 填了 A、B、D，没有 C | 选项从 A 连续填写 |
| 修改题目时删除系统ID | 保留原 ID 与基准修订号，否则会被当成新题 |
| 在 Excel「示例」表录题 | 将内容复制到「题目」表 |
| 把旧自由排版 Word 直接导入 | 使用标准字段表，旧文件只做一次迁移 |

完全相同的文件重复导入会跳过。未带系统 ID 且重新保存后的新文件不能仅凭题干可靠判定更新；更新请从系统导出，避免重复录入。

# Windows 单文件免安装版

日期：2026-10-15。版本：0.2.6，Windows x64。

本轮获取远端全部分支，按最新提交时间及提交关系选择 `codex/compact-bank-experiment`，构建基线为 `c54c0d7`。该分支包含此前 Windows 验证成果、平台目录整理及后续小程序工作；本轮只增加 Windows 免安装构建和验证入口。

## 使用

复制 `交付/题库_0.2.6_x64-portable.exe` 到需要的位置，双击即可打开。分发时只需这一个 EXE，旁边不需要 DLL、源码、Node.js、Rust、题库文件或 OCR 模型文件。无需运行安装向导，不创建卸载项或快捷方式。程序尚未进行代码签名。

- 需要系统已有 Microsoft Edge WebView2 Runtime。本机 Windows 11 x64 已具备并实际验证；没有该运行时的电脑不能直接运行这个单文件版。
- 914 道内置题、导入模板、前端及中英文离线 OCR 的 Worker / WASM / 模型随 EXE 嵌入。首次启动建立本机数据库，之后无需联网即可搜题和识题。
- 数据库继续保存在 `%APPDATA%\local.questionbank.desktop\question-bank.sqlite`，可在「设置与维护」查看路径；显示偏好和 WebView 缓存也由当前用户配置目录管理。免安装不代表运行后完全不产生数据文件。
- 与安装版使用同一个应用标识和默认数据库，原有数据继续可用。一次只运行一个版本。换电脑仅复制 EXE 不会携带编辑过的题库；可导出题库包，或退出程序后备份整个数据目录。
- 本版只嵌入应用及 OCR 资源，未嵌入整套浏览器运行时。WebView2 的固定版本部署需要附带运行时文件，参见 [微软分发说明](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/distribution) 和 [Tauri Windows 运行时选项](https://v2.tauri.app/distribute/windows-installer/#webview2-installation-options)。

`交付/` 为忽略的本机生成目录，EXE 与校验文件不提交 Git，也不会随源码克隆自动下载。

## 重新构建

先准备 Windows 构建依赖，见 [Windows 交接](../README.md)。在仓库根目录执行：

```powershell
pnpm.cmd install --frozen-lockfile
pnpm.cmd build:windows:portable
```

入口调用 `windows/scripts/build-portable.ps1`，加载已有的工作区 Rust 环境，并通过通用 Tauri 包装脚本合并 `windows/tauri.conf.json`。内部使用 `--target x86_64-pc-windows-msvc --no-bundle -- --locked`，仍执行 OCR 资源校验、TypeScript 检查和前端构建，只跳过安装器。构建失败时不会发布旧的二进制。

脚本从 Cargo 元数据确定输出目录，确认 EXE 的 PE 架构为 x64，再复制为带版本号的交付文件并生成相邻 `.sha256` 文件。PowerShell 脚本使用 UTF-8 BOM，以支持 Windows PowerShell 5.1 中的中文文件名。

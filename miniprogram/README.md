# 微信小程序：内置题库文字搜题

2026-10-15 内置首版。原生 TypeScript / WXML / WXSS，WebView 渲染；在用户创建的 TS 基础模板上实现。当前内置「HarmonyOS 初级认证」914 道题，打开即可搜索，无需另下载题库或登录。

## 直接运行

1. 微信开发者工具打开当前目录 `question-bank/miniprogram/`，即包含 `project.config.json` 的目录。不要把里面的 `miniprogram/` 子目录当工程根目录。
2. 使用工程中现有 AppID，点击「编译」。入口是 `pages/index/index`。工程已关闭开发／上传时的无依赖文件过滤，并显式包含 `data/`；本机私有配置只同步关闭了开发过滤，避免漏掉运行时读取的题库文件。
3. 页面应显示题库名、914 道题、内置版本 1。输入文字可即时搜索，清空可查看全部题目。
4. 点击「预览」，由开发者／体验者在手机上验证。当前未替用户上传体验版或发布正式版本。

构建生成的题库文件已随源码保存，首次运行不需要先安装 npm 依赖或启动服务器。小程序代码包本身仍需要微信获取；离线使用以微信允许正常启动为前提。

## 当前能力

- 输入和普通文字粘贴；空格分隔多个词同时匹配，英文双引号表示连续短语。
- 题干、选项、标签、章节、编号和题目 ID 可搜；解析和答案不参与检索。
- 单字、双字、中英文和 NFKC 规范化；300 字／12 个词限制有明确提示。
- 每个搜索词稳定配色，较远的命中片段仍显示；点击查看完整题干、全部选项、答案和已有解析。
- 连续滚动、可变高度虚拟列表；只把当前视口和缓冲区的数据传给页面。
- 输入变化使旧查询失效；内置读取错误可重试，空结果和超限均有提示。

暂未接入题库下载、后台更新、云服务、鉴权、加密、拍照／截图识题、编辑或制包分享。内置版不代表已通过 1 万／10 万题、最低支持系统或 P95 ≤ 200 ms 的真机验收。

## 更新内置题库与检查

以下命令在 `question-bank/` 仓库根目录执行，使用已有 Node.js 22.18+ 和锁文件中的 TypeScript：

```sh
pnpm prepare:miniprogram
pnpm check:miniprogram
pnpm test:miniprogram
```

本机可使用仓库工具链入口：`sh mac/scripts/env.sh pnpm check:miniprogram`。生成器默认使用桌面内置源 `src-tauri/resources/seed.json`，不自动读取桌面应用本机数据库中的维护记录。

从桌面维护后的题库生成时，先在桌面「制作离线包」，将 `.qbank.zip` 解压到独立目录，再运行：

```sh
node tools/mobile-index/build.mjs --source /absolute/path/to/unpacked-bank
node tools/mobile-index/build.mjs --check --source /absolute/path/to/unpacked-bank
```

随后重新编译小程序。此方式保留 JSONL 原始字节、题库 ID、内容版本、哈希、题目和选项 ID。使用自定义发布包后，校验也需传相同 `--source`；默认 `prepare:miniprogram` 会恢复为仓库默认内置题库。

当前生成文件：标准 `data/manifest.json`、`data/questions.jsonl`，以及绑定相同内容哈希的 `data/index.json`。914 题合计 1,743,909 字节（约 1.66 MiB）；这是未压缩数据大小，不是微信最终上传包大小。生成器设置 1900 KiB 数据预算并拒绝超限，实际上传体积以开发者工具为准。

数据统一及加密方案见 [评估文档](../docs/三端统一题库格式与加密评估.md)。当前数据未加密；差分编码只是索引体积优化。

## 开发侧已完成的检查

- TypeScript 类型检查通过；官方模板自带的 `.d.ts` 与当前 TypeScript 的约束差异通过 `skipLibCheck` 跳过，业务 TS 仍严格检查。
- 8 项针对性回归通过：真实索引与独立全文参考、跨字段／短语、排除解析、旧请求取消、Unicode 高亮、虚拟列表、搜索页面与详情数据流、生成物一致性。
